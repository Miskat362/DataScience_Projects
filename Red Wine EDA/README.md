# 🍷 Red Wine Quality EDA

This project presents an Exploratory Data Analysis (EDA) of the Red Wine Quality dataset, focusing on the physicochemical properties of Portuguese "Vinho Verde" red wines. The goal is to understand how various features influence wine quality and to uncover patterns that can help predict and enhance wine quality.

## 📊 Dataset

- **Source:** [winequality-red.csv](winequality-red.csv)
- **Features:** 11 physicochemical properties (e.g., acidity, sugar, pH, sulphates, alcohol) and 1 quality score (0–10).

## 📝 Key Insights

- Cleaned and preprocessed the data (handled duplicates & missing values)
- Conducted descriptive statistics and correlation analysis
- Visualized distributions and relationships using heatmaps, pairplots, and scatterplots
- Identified data imbalance in quality ratings
- Explored how factors like alcohol content and acidity affect overall quality

## 📑 Notebooks & Files

- [`RedWineDataset_EDA.ipynb`](RedWineDataset_EDA.ipynb): Main analysis notebook
- [`winequality-red.csv`](winequality-red.csv): Dataset

## 🧮 Tools & Libraries

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## ✨ Results

- Alcohol and sulphates show positive correlation with wine quality
- Data is imbalanced, with most wines rated 5 or 6
- Visualizations provide insights into feature distributions and relationships
