# 🚀 Data Science Portfolio: Exploratory Analysis & Feature Engineering

Welcome to my Data Science Projects portfolio! This repository features a curated collection of end-to-end data analysis, EDA, and feature engineering projects across multiple domains—including transportation, retail, food & beverage, and public sector analytics. Each project demonstrates my expertise in data wrangling, visualization, and extracting actionable insights using Python and industry-standard libraries.

---

## 📂 Project Highlights

### ✈️ [Flight Price EDA](Flight%20Price%20EDA/)
- **Goal:** Clean and engineer features for flight price prediction.
- **Techniques:** Missing value handling, time feature extraction, categorical encoding, and dataset preparation for machine learning.
- **Files:** [`FlightPrice_EDA.ipynb`](Flight%20Price%20EDA/FlightPrice_EDA.ipynb), processed datasets, visuals.

### 🚗 [Car Price Analysis](Car%20Prices/)
- **Goal:** Analyze factors influencing used car prices in the US.
- **Techniques:** Correlation analysis, brand comparison, condition impact, regional pricing, and actionable recommendations.
- **Files:** [`Car_price_Analysis.ipynb`](Car%20Prices/Car_price_Analysis.ipynb), raw data, insights, visuals.

### ☕ [Coffee Production Analysis](Coffee%20Project/)
- **Goal:** Explore global coffee production and pricing trends.
- **Techniques:** Subplots for country-wise price distributions, import/export analysis, and feature engineering.
- **Files:** [`Coffee_production_Analysis.ipynb`](Coffee%20Project/Coffee_production_Analysis.ipynb), multiple datasets, visual outputs.

### 📱 [Google Play Store EDA](Play%20Store%20EDA/)
- **Goal:** Uncover trends in mobile app popularity, installs, and ratings.
- **Techniques:** Data cleaning, transformation of date/size/install/price columns, and category analysis.
- **Files:** Cleaned datasets, EDA notebook, summary visuals.

### 🍷 [Red Wine Quality EDA](Red%20Wine%20EDA/)
- **Goal:** Analyze physicochemical properties affecting wine quality.
- **Techniques:** Descriptive statistics, correlation analysis, data imbalance detection, and visualization.
- **Files:** [`RedWineDataset_EDA.ipynb`](Red%20Wine%20EDA/RedWineDataset_EDA.ipynb), dataset, output visuals.

### 💼 [Data Analysis: Kaggle Datasets](Data%20Analysis/)
- **Projects:** 
  - **SF Salaries Kaggle:** Salary trends and compensation analysis for San Francisco public employees.
  - **Income Data Kaggle:** Factors influencing income levels, demographic analysis.
- **Techniques:** Data wrangling, bivariate analysis, and visualization.
